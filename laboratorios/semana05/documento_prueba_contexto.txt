El presupuesto de una vivienda debe organizar las cantidades de obra, los materiales y la mano de obra antes de iniciar la construcción. Cada concepto necesita una descripción clara, una unidad de medida y un precio que pueda comprobarse. Un sistema de inteligencia artificial puede ayudar a ordenar esta información y detectar datos faltantes, pero sus resultados requieren revisión profesional. Para proteger la privacidad, los documentos de prueba no incluyen nombres de clientes, correos ni ubicaciones exactas. La información utilizada en este ejercicio es ficticia y sirve únicamente para estudiar cómo un modelo procesa textos relacionados con proyectos de arquitectura.

El caso de estudio corresponde a una vivienda hipotética de un nivel. El expediente se divide en capítulos de preparación del terreno, cimentación, estructura, muros, acabados e instalaciones. Las dimensiones y los precios se agregarían mediante una hoja de cálculo independiente. En este texto no se asignan costos de mercado ni se establece una solución estructural. Su propósito es describir el flujo de información que necesita un asistente de presupuestos para identificar conceptos y pedir aclaraciones cuando falten datos.

Antes de iniciar una estimación se debe comprobar qué versión del plano está vigente. El responsable registra la fecha, el nombre del archivo y la descripción de los cambios. Si aparece una diferencia entre dos documentos, el sistema debe mostrarla y solicitar una decisión. Mezclar dimensiones de versiones distintas puede duplicar partidas o eliminar trabajos necesarios. La trazabilidad permite reconstruir el origen de cada cantidad y facilita una revisión posterior del presupuesto.

Los conceptos se escriben con un alcance concreto. Una partida de muro debe identificar el material, la unidad y las actividades incluidas. La descripción también distingue suministros de colocación y evita contar dos veces un mismo trabajo. Cuando una información no está disponible, se registra como pendiente. El sistema no debe completar espesores, resistencias ni rendimientos mediante una suposición silenciosa. Cualquier supuesto autorizado se conserva junto a la partida para que pueda ser revisado.

La medición de superficies empieza por identificar la geometría que realmente aparece en los planos. Para un recinto rectangular se multiplican largo y ancho, siempre que ambas medidas estén expresadas en la misma unidad. Los espacios irregulares se separan en figuras verificables. Una cantidad obtenida de esta forma debe acompañarse de sus dimensiones de origen. El modelo puede ordenar los datos, pero una fórmula de la hoja de cálculo realiza la operación y permite comprobarla.

Los volúmenes requieren una tercera dimensión y una descripción del elemento. Una losa, un relleno y una excavación no deben mezclarse en el mismo concepto aunque compartan una unidad. El expediente indica si las medidas son netas o incluyen ajustes. Los desperdicios se registran como un porcentaje separado y justificado por el responsable. No se aplica un porcentaje universal a todos los materiales. La compra final depende del despiece, la presentación comercial y las condiciones de ejecución.

Los precios unitarios se guardan con su fecha de consulta, moneda, unidad y alcance. Dos cotizaciones solo son comparables si incluyen las mismas condiciones. Transporte, impuestos y colocación pueden cambiar el resultado. El sistema debe advertir cuando no conoce alguno de estos componentes. Para esta práctica se usan registros ficticios que permiten ensayar el formato sin publicar acuerdos comerciales. La actualización de precios conserva el valor anterior en un historial de cambios.

La revisión del catálogo verifica que cada concepto tenga una clave única y pertenezca al capítulo correcto. También busca unidades incompatibles, duplicados y campos vacíos. Una cantidad negativa se considera un dato que requiere revisión, salvo que esté documentada como una deducción. El asistente recibe únicamente la información necesaria para la tarea solicitada. Las descripciones pueden generalizarse cuando un detalle no afecta al presupuesto. Los nombres de personas se sustituyen por etiquetas y las ubicaciones se presentan a nivel general. Antes de compartir planos o fotografías se revisan los rótulos y los metadatos. Esta práctica utiliza un expediente ficticio porque el objetivo consiste en estudiar el procesamiento del texto y no en divulgar un proyecto real.

Cada consulta define la salida esperada. Una solicitud de extracción pide una tabla de concepto, cantidad, unidad y fragmento de respaldo. Si el documento no contiene un valor, la salida debe indicarlo. Una solicitud de ideas permite explorar alternativas, pero las presenta como propuestas sujetas a evaluación. Separar estas tareas ayuda a reconocer cuándo una respuesta busca precisión y cuándo ofrece posibilidades. El estilo convincente de una frase no demuestra que sus datos sean verdaderos.

La revisión humana compara cada respuesta con el texto de origen. Si una descripción menciona un material que no aparece en el expediente, se marca como información no sustentada. Si omite una condición importante, se solicita una corrección. El responsable conserva la pregunta y la respuesta para poder repetir la revisión. Cuando cambia el archivo de entrada se vuelve a comprobar la salida, ya que una respuesta anterior puede haber perdido vigencia.

La documentación se conserva en carpetas con nombres consistentes. Una carpeta de trabajo contiene borradores y otra guarda versiones aprobadas. El equipo utiliza controles de acceso y evita compartir enlaces abiertos con datos personales. Los archivos de laboratorio pueden publicarse únicamente cuando contienen información ficticia o suficientemente anonimizada. El repositorio registra el motivo de cada cambio para que el avance del proyecto pueda revisarse de forma ordenada.

Un documento extenso puede dividirse en secciones temáticas con identificadores de origen. Cada fragmento conserva suficiente contexto para entender sus unidades y condiciones. Dividir por un número fijo de caracteres puede cortar una partida o separar una excepción de la regla que modifica. Por eso conviene respetar capítulos y párrafos. Cuando la pregunta relaciona varias secciones, el sistema debe recuperar todas las partes necesarias antes de proponer una respuesta.

Las pruebas del asistente incluyen preguntas cuya respuesta se conoce de antemano. Una prueba puede pedir un identificador interno y otra puede solicitar un dato ausente. La respuesta correcta al dato ausente es reconocer que no aparece. Estos casos permiten distinguir una recuperación adecuada de una invención. También es necesario probar información contradictoria, porque el modelo debe mostrar el conflicto en lugar de elegir un valor arbitrario.

El registro de resultados anota el servicio utilizado, el modelo visible, la fecha y los parámetros disponibles. Las respuestas se guardan literalmente antes de analizarlas. Para estudiar variabilidad se mantiene igual la pregunta y se inicia una conversación nueva en cada ejecución. Si la temperatura no puede controlarse, se registra como desconocida. Pedir una redacción creativa cambia las instrucciones, pero no permite afirmar que se configuró un parámetro numérico del modelo.

El presupuesto preliminar termina con una lista de datos pendientes, supuestos autorizados y revisiones realizadas. Antes de utilizarlo se comprueban las operaciones y la correspondencia entre planos y conceptos. El sistema se considera una herramienta de apoyo para organizar información. La decisión final corresponde al responsable del proyecto. Este expediente puede ampliarse con nuevas partidas ficticias para repetir las pruebas y comparar resultados bajo el mismo procedimiento.
